Words to know

Key vocabulary

Input

the data that goes into the system, such as text, an image or a sensor reading

Model

the trained process in the middle that turns an input into an output using patterns learned from data

Output

what comes out: a label, a prediction or a new piece of content

Pipeline

the stages joined in order, from input through the model to output

Evaluate

to judge how good an output is by checking it against the task and a trusted source

Use these words in your explanations today.

Part 1

One pipeline, three stages

INPUTThe data that goes in: text, an image or a sensor reading
➜
MODELTrained on past examples; turns the input into a likely result
➜
OUTPUTWhat comes out: a label, a prediction or new content

Pipeline = the stages joined in order. One prediction runs forward, but building an AI is a loop: test, evaluate, feed back, retrain.

Part 3

The model is not magic

  • It predicts from learned patterns. It does not think or understand.
  • An unusual or unclear input can lead to a strange output.
  • A confident-looking output is not always correct, so check it, don’t trust it.

No board demo? Use simulated-AI cards: a “model” envelope holds a fixed rule; post an input card in and it returns the matching output card.

Summary

  • Almost any AI tool is a pipeline: input, model, output.
  • One prediction runs one way; development runs in a loop.
  • The model predicts from learned patterns. It does not think.
  • Naming the stages lets you find where a result was shaped and evaluate it.
